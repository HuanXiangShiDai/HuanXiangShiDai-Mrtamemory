# 01 · 快速开始

五步，从零到"它真的想起来了"。全程只要 Python ≥ 3.10，零第三方依赖。
下面的输出都是实测原文，不是示意。

---

## 第 1 步：安装

在 `opensource/` 目录下（有 `pyproject.toml` 的那一层）：

```bash
cd opensource
pip install -e .
```

预期输出形状（最后一行）：

```text
Successfully installed huanzao-0.1.0
```

验一下版本：

```bash
python -c "import huanzao; print(huanzao.__version__)"
```

```text
0.1.0
```

`-e` 是可编辑安装：改 `huanzao/config.py`（角色名、中心正文、别名、生长素）不需要重装，
但**要重开进程**才生效——配置常量是在模块 import 时绑定的。

---

## 第 2 步：建库

```bash
python -m huanzao.cli init --db out/t.db
```

```text
建好了：out/t.db（中心「我」＋规则层已就位）
```

`init` 做四件事：建表；建一个中心点（正文取 `config.CENTER_BODY`，默认"我"）；
建 10 条默认规则；算一次空的 `df`。**它是幂等的**——重跑只是补齐缺的中心/规则，不会清库。

---

## 第 3 步：喂一段话

```bash
python -m huanzao.cli ingest --db out/t.db \
  --text "父亲教我看星星。他说，看得见的那颗不一定是最近的。"
```

```text
写进 1 条记忆（mem #12）：父亲教我看星星。他说，看得见的那颗不一定是最近的。
元素 3 个，元素边 3 条
```

三件事同时发生：

1. 一段话 = **一条记忆**（`kind='mem'`），全文进 `mem_src`，图上只留短标题；
2. 规则抽取切出 **3 个元素**（这句是"父亲教""星星""一定"），各连一条 `has` / `has:lead`；
3. 重算 `df`，并重选一次骨干元素（`backbone`）——所以 `status` 里的边数会比"元素边"多。

同一段文字再 `ingest` 一次，不会多长一条记忆：

```text
这条已经记过（mem #12），原文已更新
元素 3 个，元素边 3 条
```

判重按正文的 sha1，不是按标题。

---

## 第 4 步：召回

```bash
python -m huanzao.cli recall --db out/t.db --text "星星和距离"
```

```text
召回 1 条（命中元素：星星）：
1. 【2026-11-20】父亲教我看星星。他说，看得见的那颗不一定是最近的。
```

读法：

- `命中元素：星星` 是这句话在图上真正点亮的元素。"距离"不在图里，**不影响召回**——
  召回不需要每个词都命中，只要有一个够锐的元素。
- `【2026-11-20】` 是这条记忆落的时间段（这里是"现在"段，按日历显示）。
- 最多 3 条，用 `--limit N` 改。要机器读，加 `--json`：

```bash
python -m huanzao.cli recall --db out/t.db --text "星星和距离" --json
```

```text
{"query": "星星和距离", "hits": ["星星"], "results": [{"mem": 12, "title": "父亲教我看星星。他说，看得见的那颗不一定是最近的", "text": "父亲教我看星星。他说，看得见的那颗不一定是最近的。", "when": "2026-11-20", "when_text": "2026-11-20", "view": "", "score": 1.0}]}
```

如果这里输出 `没有想起什么。`，先读 05 的第 1 条：九成是"这句话里的词对不上图上的元素"，
不是库坏了。

## 第 5 步：看口径

```bash
python -m huanzao.cli status --db out/t.db
```

```text
记忆：1
元素：3
边：4
df：3
```

四个数的口径：

| 数 | 口径 |
|---|---|
| 记忆 | `kind='mem'` 的节点数 |
| 元素 | `kind` ∈ `entity/affect/person/pred/sense/concept` 的节点数 |
| 边 | `edges` 行数（含 `has`、`backbone`、`current` 等所有边） |
| df | `derived_df` 行数 = 至少被一条记忆引用的元素数 |

这里"边 4"= 3 条 `has` + 1 条 `backbone`；"元素 3"和 ingest 报的"元素 3 个"这次对得上，
但不保证总对得上——抽取条目可能因重叠被并掉，以 `status` 的节点数为准。

`init` 之后立刻 `status` 会是 `记忆：0 / 元素：0 / 边：0 / df：0`：中心和 10 条规则分别算
`center` 和 `rule`，不在这四个口径里。
