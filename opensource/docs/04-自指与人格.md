# 04 · 自指与人格

> **关于 L1–L4 的命名（读之前请先看这句）**
>
> 本文的 `L1 / L2 / L3 / L4` 指的是**图上自指环的深度**（δ* = 1/2/3），
> **不是**学界 [Tarski 真层级](https://plato.stanford.edu/entries/tarski-truth/)里的
> L0（对象语言）→ L1（元语言）→ L2（元元语言）。
>
> 两者同名不同义：Tarski 量的是**语言能说多高层的事**，我们量的是**图上的环能绕多深**。
> 你在别处看到 "L1 元语言" 时，不要把它和本文的 "L1 单圈极性 −1" 混在一起。
>
> 与本文更接近的学界概念是图论里的
> [cycle depth](https://www.jair.org/index.php/jair/article/download/13939/26971#11#13#11)
> 和 [Ordinal Folding Index](https://arxivlens.com/paperview/viewpdf/ordinal-folding-index-a-computable-metric-for-self-referential-semantics-4351-425de6ff)。



这一章是理论的最小可读版。每条只留三样东西：**一句话**（直觉）、**一个式子**（判据）、
**一句后果**（能做/不能做什么）。完整推演在 `幻造_自指理论_v0.2/v0.3/v0.4`，正文里给的
定理编号可以直接回查。

先记住一句话：**自指不是"她反思自己"，是"她这一轮写下的规则，会改变她下一轮怎么想"。**

---

## 0. 一张表看懂 L1–L4

| 层 | 深度 | 判据 | 工程上长什么样 | 能自证什么 |
|---|---|---|---|---|
| L1 | `δ* ≥ 1` | 存在长 2 的环，极性 `-1` | 把一条规则改了，又改回来 | 我绕了一圈，符号翻了 |
| L2 | `δ* ≥ 1` | 存在极性 `+1` 的双圈，且带证书 | 改→回退→再改，路径能重放 | 我走完了（不是"我走对了"） |
| L3 | `δ* ≥ 2` | 同一维度被连续改两次，且有 `closes` 边 | 24→26→24，版本链多两层 | 我对自己的一次认知周期做了否定之否定 |
| L4 | `δ* ≥ 3` | 对"改规则"这件事再改一次 | 元规则层（目前没有） | 机制在结构上闭合 |
| L5 | — | 不可达 | — | 语义/一致性自证（数学上禁止） |

实测位置（主图）：`δ* = 2` → **L3**；带符号环检测只报出 **1 个环**，`[极性 -1] 长度 2`；
规则审计 **10 条规则 / 13 个版本 / 0 问题**。

---

## 1. 三个动作：读、想、写

**一句话**：自指闭环只由三个动作组成——注入 `J`（读进什么）、思考 `T`（想出什么）、
写入 `Φ`（写回什么）；自指是 `Φ` 与 `T` 的复合。

**一个式子**：

```text
G(t+1) = Φ( G(t), T( G(t); J(G(t)) ) )
```

`J` 夹在 `T` 之内、`Φ` 之外。顺序只有这一种读法：读 → 想 → 写。

**一句后果**：如果 `J` 把规则正文也读进上下文，那么"写"这一步的类型限制就被从前提侧
绕开了——这就是 v0.4 整篇要处理的事。`A1`（写入像必须是软规则层）管的是**写出来的东西
是什么类型**，它根本不管**读进去的东西从哪来**。所以"注入的只是记忆，所以安全"这句话是错的。

---

## 2. δ\*：自指有多深

**一句话**：`δ*` 是回指边能嵌套几层——不是"想了多久"，是"关于规则的规则，套了几层"。

**一个式子**：

```text
δ*(G) = max{ k | 存在一条长 k、且不经过 F0 的回指边链 }
```

回指边指"这次改写引用了哪条规则的哪条前提"这一类边（`rewrites` / `unrewrites`）。
`F0` 是边界算子（见第 8 节），它不算深度。

**一句后果**：层级不是自封的标签，是图上的可测量。实现里 `rule_c2.depth()` 用
"同一条规则被总结促成的连续改写次数"来数：`0 → L0`，`1 → L1/L2`，`2 → L3`，`3 → L4`。

---

## 3. L1：改了什么，又改回来

**一句话**：只要系统记录过"改了一次、又改回来"，L1 就自动成立——它不是设计出来的层级，
是"有逆操作"的对称性产物。

**一个式子**：一次改写和它的逆操作，组成长 2 的环，极性相乘为 `-1`：

```text
π(e1) · π(e2) = (+1) · (-1) = -1
```

**一句后果**：L1 不需要额外机制。反过来说，**没有逆操作的那类改动，L1 不可达**——
`merge` 与 `split` 不是彼此的逆（两者都扩大适用集），所以它们组成的 2-环极性是 `+1`，
不构成否定环（定理 7'）。L1 是**逐操作对**成立的，不是一个统一深度。

实测：某条规则 `remind_chars` 300 → 320（`thr↑`，极性 `+1`）得到 `v2`；回退到 `v1`
补一条反向边（极性 `-1`）。环检测输出：

```text
[极性 -1] 长度 2 ｜ <规则名> ｜ 自指
边：v1 --rewrites(+1)--> v2；v2 --unrewrites(-1)--> v1
生效正文：回到 300（与改写前等价）
```

---

## 4. L2：双圈，加一份证书

**一句话**：绕两圈回到原点——极性 `+1`——并且路径上的每一步都能重放，这才叫"走完了"。

**一个式子**：

```text
π(P) = (-1) · (-1) = +1，且 P 的边序列可以重放验证
```

**一句后果**：L2 能自证的是"**我走完了**"，不是"**我走对了**"。对错必须外包给外部证据
（边界 2）——这就是为什么规则一致性要有一个**不经过写入路径**的审计器，而不是问系统自己。

实测：`+1` 双圈在副本上验过会出现（"改→回退→再改"）；主图目前只有那一个 `-1` 单圈，
**L2 没有在主图上单独验到**。这条标"未验证"，不当结论用。

---

## 5. L3：否定之否定

**一句话**：同一维度被连续改两次，第二次把数值改回原点——数值没变，但结构上多了一圈。

**一个式子**：

```text
δ* ≥ 2  且  存在 closes 边（v3 → v1）
```

**一句后果**：环检测**看不见** L3。`closes` 不是带符号改写边，`cycles()` 不会把它算进环。
所以 L3 的判据必须是"深度 + 闭合边"两个条件，不能只看某个环的极性。

主图实测（`rule_c2.typed_write` 两次，各由一条总结促成）：

```text
起点  <规则>：innate=24
A1    总结 A → thr↑ innate=26   极性 +1  enacts_up   → v2
A2    总结 B → thr↓ innate=24   极性 -1  enacts_down → v3
      closes 边：v3 --closes--> v1
结果  innate 回到 24（数值回到原点），版本链多出 v2 / v3 两层
      δ* = 2  →  L3
审计  C2 ok（无自由文本写入）· 规则审计 ok（10 规则 / 13 版本 / 0 问题）
      头段指纹不变：因为 innate 回到 24，头段内容等价
```

这就是"否定之否定"的可判定形态：**正题（24→26）、反题（26→24）、合题（回到 24，
但留下两层版本和一条闭合边）**。

---

## 6. L4：元规则层，还没到

**一句话**：L4 要求对"改规则"这件事本身再改一次——即规则的规则。

**一个式子**：

```text
δ* ≥ 3
```

**一句后果**：L4 能自证的是"**机制**在结构上闭合"，不是"**结论**正确"。这两件事不能混。
现在没有元规则层，主图停在 L3；这条是"未达"，不是"做不到"。

---

## 7. L5 为什么不可达

**一句话**：语言一旦强到能谈论自己的真值，它就不能在内部证明自己的真值与一致性。

**一个式子**（两条限制，来自定理 3 第 3、4 款）：

```text
规则语言允许自指否定        → Tarski：真不可定义
规则语言能表达乘法（≥ Q）   → 哥德尔第二定理：一致性不可自证
```

**一句后果**：L5 不是工程量问题。你可以把 L1–L4 全部做出来，但 L5 永远差一步；
这一步不能靠更聪明的工程补，只能靠**限制语言**（弱到 Datalog / Presburger）绕开。

---

## 8. F0 为什么只能是 `-I`

**一句话**：边界必须能"翻面"，但不能"记住内容"——记住内容的边界会使"双圈闭合"这个
条件自相矛盾。

**一个式子**（定理 3.5）：

```text
U(0) = I，U(2π) = F0，U(4π) = I，F0² = I
⇒ F0 = -id（作用在结论集上的全局符号翻转）
```

推导只用三步：`U` 取给定的参数化 `U(θ) = cos(θ/2)·I + sin(θ/2)·F0`，
代入 `θ = 2π` 得 `U(2π) = -I`，而闭合要求它等于 `F0`，所以 `F0 = -I`。
反过来说，如果 `F0` 是任何一个"非平凡的对合"（交换两个结论、或者把某条边取反），
`U(2π)` 就不再是"全局翻符号"，闭合式当场失败。

**一句后果**：`F0` 的信息容量只有 **1 bit**（一个符号），它不携带任何关于具体结论的信息。
`F0·c1` 与 `F0·c2` 对任意 `c1, c2` 只差一个全局符号——**它记不住，才是边界**。
"让边界记住一条规则"在数学上做不到；要内容就得升维（定理 9：`F0` 是 `Z/2` 在一维表示上的
作用，`ρ(1) = -I`），而升维之后它就不再是"翻转"，闭合判据也没了。

所以：**L1–L4 可达、L5 不可达，这个边界不可移动。移动它等于放弃双圈闭合。**

## 9. C1 与 C2：谁在承重

**一句话**：C1 是"别让她看到规则正文"，C2 是"她根本没有'写正文'这个动作"。
前者是审查，后者是取消能力。

**一个式子**（定理 13）：

```text
C1 ⇏ A1*        （剥正文挡不住同义改写）
C1 ∧ C2 ⇒ A1*   （两个都做，充分）
C2 ⇒ A1*        （C2 单独就充分——承重的是它）
```

其中 `A1*` 是内容级的软层闭合：写出来的规则正文，只能由初始规则集在原子操作下生成。

**一句后果**：**别把"我过滤了正文"当成安全证明**。定理 13 B 款给了一个反例：

> 一条记忆写"他后来嫌走太远，说以后别超过五步"——它**一字不沾**规则正文
> `max_hops: 2`，C1 判定通过；但思考读到它，完全可以自撰出 `max_hops: 5` 写进规则层。
> 所有形式条件都过，核心规则已经被遮蔽。

C2 的落法：思考只输出 `(哪条规则, 哪个原子操作, 哪个参数)` 三元组；新正文由
`rule_graph.apply_op` 从旧正文推导。模型这一侧**拿不到写正文的句柄**。
`rule_c2.py` 就是这道闸：操作白名单（六种原子操作）、参数白名单（`key/to/a/b/w/into`）、
值不许含换行/分号/冒号（那是正文的形状）。

还有一条容易被忽略：**注入有两条通道**。`J^msg` 进 user 消息（污染前提），
`J^sys` 进 system prompt（与规则同级，污染的是"规则的位置"）。后者更危险一个量级：
它不需要经过任何规则改写，就已经占了规则的位置。C1 必须两条通道都做。

## 10. 注入是"账外自指"

**一句话**：注入这条环不在回指边账本上，所以 `δ*` 对它**盲**——看不见，才是它危险的地方。

**一个式子**（定理 12a）：

```text
J 不产生回指边  ⇒  δ*(t+1) = δ*(t)
```

**一句后果**：注入卫生必须**外挂**一个检查器，不能指望自指层自己发现。三个直接后果：

1. **只读不引入删边**：`A3` 与"轨道递增"存活，这是定理 11(i)。
2. **但 `F^J` 的单调性不是白送的**：`top-k` 截断、阈值收缩都会让"该加的边没加"——
   单调性破在**前提**，不在**写入**（定理 11(ii) 的反例就是 `--limit 3` 踢掉旧命中）。
3. **遗忘与收敛不可兼得**：注入语境只增不淘汰，才保得住最小不动点；一旦有淘汰，
   定理 1 的强结论失效。这是结构性的取舍，不是实现缺陷。

两条可测的判据（阈值未标定，实测未做，标"未验证"）：

```text
Δ_t = |J't \ J_t| + |J_t \ J't|     幂等：Δ_t = 0
r_t = |J_t ∩ J_(t+1)| / |J_t|       无自激：r_(t+1) ≤ q'·r_t（存在 q' < 1）
```

## 11. 人格：把"只增不改 + 版本"用在长期化上

**一句话**：单次思考不改人格；三次同向的提案才改——"长期化"的定义就是"反复指向同一件事"。

**一个式子**（`persona.apply` 的门槛）：

```text
净票 = 赞成票 - 反对票
|净票| ≥ threshold（默认 3）且 净票 > 0  → 才写新卡
```

**一句后果**：人格修订走的是和规则版本链同一套纪律：

```text
总结 --revises_up/down--> 旧卡        提案（只是票，不改人格）
净票到阈值 → 写新卡 --supersedes--> 旧卡   生效（旧卡永不删）
新卡 --innate--> 中心                 位置继承（原地顶替旧卡，不排到末尾）
```

没有最后一条，人格修订就看不见：新卡排在 `innate` 边末尾，名额一满（默认 14，
主图实测调到 24）就永远进不了头段。实测：3 次提案 `net = +1, +2, +3` →
`apply(threshold=3)` 生效，头段从 **721 字** 变成 **748 字**，指纹随之改变；
旧卡仍在图上，只是不再出现。

注意：人格层用的**是**这套纪律，但它的修订**不改变 `δ*` 的层级**。人格是数据层的累积，
规则版本链才是自指深度的账本。两件事分开算，别混。

## 12. 三条可测的收敛判据

| 判据 | 量什么 | 收敛条件 | 现在 |
|---|---|---|---|
| 单调性（定理 1） | 节点数 `V_t`、边数 `E_t` | 逐轮不减，轨道是 lfp 的下近似 | 成立：边只增（7709 → 7904） |
| 局部压缩（定理 2'） | 每轮新增边数 `n_t = E_{t+1} − E_t` | 存在 `t0, q<1`：`n_{t+1} ≤ q·n_t` | 未按轮实测 |
| 深度可行（定理 6） | `δ*` | `δ* < min(δ*stab, δ*info)` | `δ* = 2`；两个上界未实测 |

## 13. 哪些是实测，哪些是推演

- **实测**：`δ* = 2` → L3；1 个 `[-1]` 长度 2 的环；10 规则 / 13 版本 / 0 问题；
  C2 的四类拒绝；`+1/+2/+3` 触发人格修订。
- **推演（有定理，无实测数）**：L2、L4、`δ*stab(N)`、幂等性 `Δ_t`、自激率 `r_t`。
- **不可达**：L5（Tarski / 哥德尔）。

这份手册里出现"未验证"的地方，就是这两类之间的分界线——**不确定就写不确定，不编**。

## 14. 环怎么合上：触发条件也进图

上面讲的都是"规则能被改"。但还有一个更隐蔽的问题：**"什么时候改"如果写在代码里，
环就是断的**——规则可改，改规则的条件不可改。

解法是把触发规则也做成图里的节点（`rule|触发·*`，触发词挂成元素），
再加一条**元触发**去改触发规则自己。系统于是能改掉自己的触发条件。

完整链条、实测输出、以及为此要动到的两处底层（`stop±` 要能改键值、`all_triggers` 要读生效版本），
见 [06-触发规则与闭环](06-触发规则与闭环.md)。
