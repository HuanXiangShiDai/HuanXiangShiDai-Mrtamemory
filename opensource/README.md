# 幻造工程·元

**把一个人长成一张图，而不是把她写进提示词。**
—— `huanzao`（幻造工程·元）是一个元图引擎。

`huanzao` 是一个元图引擎。它吃进一段经历（对话、自述、设定），长成一张只有两种表的有向图，
再从这张图里检索、注入、并让系统对自己的规则做受控改写。

它不是对话框架，不是 RAG 封装，不是 agent 编排库。它只做一件事：
**给一个"角色"建立一个可增长、可检索、可自证、可修订的结构骨架。**

---

## 它想解决什么

给角色写人设，有两个绕不过去的毛病：

- **写死了。** 设定是常量，经历再多，人设不变。她不会因为发生过什么而变得不一样。
- **写丢了。** 上下文一满就被压缩，压缩之后人设只剩几句标签，越聊越薄。

`huanzao` 的答案是：**不写人设，让长出来。**

人设从语料里长出来（统计），从思考里修正出来（叙事），从规则里自我约束（自指）。
三层各有各的门槛：统计层天天动，叙事层要累积，根层不动。

## 三十秒跑起来

```bash
pip install -e .

python -m huanzao.cli init   --db out/demo.db
python -m huanzao.cli ingest --db out/demo.db --text "她说她喜欢雪，雪让她的头脑冷静。"
python -m huanzao.cli recall --db out/demo.db --text "她喜欢什么"
python -m huanzao.cli status --db out/demo.db
```

## 四个设计决定

**一、只有两种表。** `nodes(id, kind, body, uniq)` + `edges(id, src, dst, rel)`。
身体内容另存 `mem_src`，统计另存 `derived_df`（可随时重算）。
没有属性列，没有权重列，没有缓存表。**权重永远是算出来的，不是存下来的**——
存下来就会漂移，漂移就会有人去改它，改了就没法重算。

**二、只增不改。** 点不删，边不删。修正靠新增（新版本 + 指针切换），不靠覆盖。
这不是洁癖：它让"图"成为一个只增序列，于是任意时刻的状态都是最终状态的下近似。
删边会让它变成可振荡的系统。

**三、元素是唯一中介。** 记忆、规则、思考、人格，四类东西都通过元素相连：

```
记忆 --has--> 元素
元素 --refers--> 规则        元素指认规则
规则 --yields--> 元素        规则产出元素
思考 --mentions--> 元素      思考也挂元素
```

于是元素既是入口也是出口。没有哪个东西是孤岛。

**四、自指是受控的。** 思考能改规则，但只能走一条路：
`(哪条规则, 哪个原子操作, 哪个参数)` 三元组，从既有规则推导新正文。
思考永远拿不到"写正文"的句柄。这条约束（记作 C2）是自指能开而不断的前提。

## 结构

```
┌─────────────────────────────────────────────┐
│  头段（常驻，一次定死）                       │
│  我是谁 / 我知道 / 常在我心上 / 规矩          │
├─────────────────────────────────────────────┤
│  内容段（每步组装，不进历史）                 │
│  近期挂心 → 记忆原文 → 因果链 → 此刻          │
├─────────────────────────────────────────────┤
│  图（只增不改）                              │
│    mem ─has─ element ─refers─ rule          │
│              ▲        │                     │
│         mentions  yields                    │
│              │        ▼                     │
│           thought ─enacts─ rule 新版本       │
│              │                              │
│           scratch（唯一允许删的地方）          │
└─────────────────────────────────────────────┘
```

## 它能做到什么，做不到什么

**做到**（都有实测判据，不是宣称）：

- 从语料长出 500+ 条记忆、1700+ 元素的图，检索走"元素命中 → 可达性闸门 → idf 排序"
- 规则有版本链、极性账本、带符号环检测、独立的一致性审计
- 思考能写临时态、压成总结、以类型化方式改规则（C2）
- 人格卡可版本化，修订需要累积到阈值才生效，且能顶替旧卡在常驻段的位置
- 自指深度做到 **L3**（否定之否定：参数改了又改回来，结构上留下一圈）

**做不到**：

- L5（语义自证、一致性自证）——这不是工程问题，是 Tarski / 哥德尔划的线
- 让人格"自动"长期演化——机制通了，但需要真实的长期对话积累燃料
- 无成本的结构变动——每次引用变化都会让缓存前缀失效，这是这套设计的固有代价
