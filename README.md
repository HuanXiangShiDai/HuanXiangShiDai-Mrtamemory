# HuanXiangShiDai-Mrtamemory
一款基于元图开发的,拥有自指功能的记忆库。
思想是规则和记忆抽离成元素，图负责控制元素，元素同时指向规则和记忆，这也就意味着记忆会改变，规则也会改变。
经实测我将崩坏三中角色爱莉希雅的文本资料进行第一人称的描述更改后，使用逐步演化的方式进行生成，最后达到了伪L3的程度。
同时值得注意的是，人格和习惯的内容本身是可被命中的，这也就意味着人格的可塑性。
经过实测发现的问题：
1.由于改过思考协议，messages和system这就导致缓存命中无法保证，因且并没有做出太多的适配。这是为了摆脱上下文的束缚和自指做出的妥协。
2.是由第一个问题和系统本身1.0版本所导致的约束，我现在并没有给他添加工程能力方面的适配，这个问题会在2.0版本得到解决。
3.需要有目的的训练才能导向更高的自指层级，因为我本身写的规则并不够完善，甚至说不够自洽，他只是提供了一个框架，需要根据实际场景进行不断的修改和学习进化（但是编者已经没有能力进行特别深入的实际研究了这方面需要付出的金钱成本我无力承担，或许有能力的人可以尝试一下能否达到伪L4的程度）。
后期的规划：接下来我会给他添加工具能力的规则适配，使其做到能够在图中调动和使用工具。在整个工程的规划中，目前的引擎系统是克莱因瓶的底部，它应当还有别的系统来组成适配，所以我想尽快解决这个引擎遇到的事。
并且要注意现在的引擎中并没有自行添加规则的规则，这方面会在1.11得到解决。
